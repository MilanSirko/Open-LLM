# Contributing to Open LLM

First off, thank you for considering contributing to Open LLM! It's contributions like yours that make open-source software such a great tool for everyone.

---

## 🛠️ How to Contribute

### 1. Report Bugs or Request Features
* Check the [Issues](../../issues) page to see if your bug or feature request has already been posted.
* If not, open a **New Issue** with a clear title and a detailed description.

### 2. Submit Code Changes (Pull Requests)

1. **Fork the repository** to your own GitHub account.
2. **Clone your fork** to your local machine:
   ```bash
   git clone [https://github.com/milansirko/Open-LLM.git](https://github.com/milansirko/Open-LLM.git)
   cd Open-LLM

 ## Please use standard prefixes for your commit messages:
- feat: New feature
- fix: Bug fix
- docs: Documentation changes
- style: Code formatting, missing semi-colons, etc.
- refactor: Code restructuring without feature/bug changes
