Quickstart

Drop-in compatible with the OpenAI SDK

Already using OpenAI's client? Point base_url at Open LLM and you're done. Every request is routed, load-balanced and given automatic fallback.

Read the docs
quickstart.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://open-llm-2fgm.onrender.com/v1",
    api_key="YOUR_API_KEY"
)

response = client.chat.completions.create(
    model="openai/...",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
